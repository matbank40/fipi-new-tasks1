# ФИПИ: новые задания

Telegram-бот следит за открытым банком заданий ЕГЭ на ege.fipi.ru (профильная математика, физика, информатика, русский) и присылает новые задания карточками: условие и рисунки берутся из банка как есть, без пересказа и генерации. Поля ответа вырезаются, приложенные файлы (информатика) приходят отдельными документами.

## Как это работает

1. Раз в `SCAN_EVERY_HOURS` часов бот проходит каждый банк постранично.
2. ID заданий сравниваются с базой (`data/fipi.sqlite3`).
3. Первый проход по предмету ничего не рассылает — только запоминает всё, что есть.
4. Новое задание: картинки скачиваются, карточка рендерится в PNG (headless Chromium), рассылается подписчикам и в канал (если задан).
5. Если «новых» за раз больше `MAX_NEW_PER_SCAN` — бот не спамит, а пишет админу: `/approve_<предмет>` или `/skip_<предмет>`.
6. Если ФИПИ на профилактике или лежит — проход пропускается, ничего не теряется.

## Установка на сервер

```bash
# с компьютера: закинуть архив
scp fipi_bot.zip root@132.243.190.127:/opt/

# на сервере
ssh root@132.243.190.127
cd /opt && apt-get install -y unzip && unzip fipi_bot.zip && cd fipi_bot
./install.sh
nano .env                      # BOT_TOKEN и ADMIN_IDS
systemctl enable --now fipi-bot
journalctl -u fipi-bot -f      # смотреть логи
```

## Важно про профилактику 22–27.10.2026

Первый проход запоминает банк «как есть». Если бот впервые запустится после профилактики, задания, добавленные во время неё, он посчитает старыми. Чтобы их поймать, до первого запуска загрузи старые ID, если они есть (например, из парсера профильной математики):

```bash
venv/bin/python -m fipi_bot.seed math ids_math.txt
```

## Команды

- `/subjects` — выбрать предметы
- `/status` — когда проверял банк, сколько заданий в базе
- админ: `/scan` — проверить сейчас, `/approve_math`, `/skip_math` и т.д.

## Если ФИПИ поменяет вёрстку

Весь разбор HTML — в `fipi_bot/fipi.py` (`parse_blocks`, `parse_info`, `clean_task_html`). Шаблон карточки — `fipi_bot/templates/card.html`.

Проверка без сети: `python -m tests.test_offline` и `python -m tests.test_scan`.
